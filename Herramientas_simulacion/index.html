PSSE (Power System Simulator for Engineering)

Ampliamente utilizado para estudios de estabilidad transitoria y flujo de potencia en sistemas de gran escala. Incluye modelos específicos para aerogeneradores y plantas fotovoltaicas.

DIgSILENT PowerFactory

Ofrece capacidades avanzadas para modelamiento de componentes renovables y análisis de armónicos. Su interfaz de programación permite la implementación de modelos personalizados.

MATLAB/Simulink

Proporciona flexibilidad para el desarrollo de modelos detallados y controladores avanzados. La toolbox Simscape Power Systems incluye bibliotecas para componentes renovables.

OpenDSS

Herramienta de código abierto especializada en análisis de redes de distribución con generación distribuida renovable.
